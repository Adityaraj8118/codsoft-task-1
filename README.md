# Password Generator (CodSoft Internship – Task 1)

Python script I wrote for Task 1 of my Python programming internship at CodSoft. It generates a random 10-character password using lowercase letters, uppercase letters, digits and symbols.

## How it works

The script combines the character sets into one string and uses `random.sample()` to pick 10 characters, then prints the password.

## Running

Requires Python 3. No external libraries.

```bash
python "Password generater.py"
```

Example output:

```
The Generated Password is : k#T3p@Lw!9
```
